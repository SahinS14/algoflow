# Algoflow

> Build your problem-solving rhythm.

Algoflow is a modern DSA practice and progress-tracking platform designed to turn interview preparation into a structured, measurable learning workflow.

Instead of using a static DSA sheet, Algoflow combines problem tracking, topic-wise progress, bookmarks, search, personalized study planning, authentication, and cloud synchronization in a single workspace.

---

## Overview

DSA preparation often becomes difficult to manage as the number of problems increases.

Algoflow provides a focused workspace where users can:

- Organize problems by topic
- Track solved problems
- Monitor overall and topic-level progress
- Bookmark important problems for revision
- Search problems by name, topic, or company
- Filter unsolved and bonus problems
- Create personalized study schedules
- Synchronize progress across sessions and devices
- Maintain an authenticated personal learning space

The current dataset contains **415+ DSA problems** across core interview-preparation topics.
